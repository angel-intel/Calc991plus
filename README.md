# Sheet Music Progress

A small personal web app for tracking how far along you are in learning each piece of sheet music, section by section.

## How to use it

Open `index.html` in any web browser. There's nothing to install.

1. Add a piece (title and composer).
2. Open it and split it into sections (e.g. "Intro, bars 1–14").
3. As you practise, move each section through the stages:
   Not started → Reading notes → Slow & steady → Up to tempo → Performance ready.
4. The piece's overall progress is the average of its sections.

Your data is saved in your browser on this device. Use **Export backup** to save a copy as a file and **Import backup** to restore it.

## Files

- `index.html` – the page structure
- `style.css` – how it looks
- `app.js` – how it behaves (saving data, adding pieces and sections)
